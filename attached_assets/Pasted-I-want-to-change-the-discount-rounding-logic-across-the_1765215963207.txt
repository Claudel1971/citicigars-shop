I want to change the discount rounding logic across the whole project.

Business rule (VERY IMPORTANT):
The discounted price must now be rounded to the nearest multiple of 500 (not 250 anymore).

Mathematically:
discounted = price * (1 - percentage / 100)
Then:
finalPrice = round(discounted / 500) * 500

Please update all the following places accordingly and keep the code clean and consistent:

1) src/utils/priceCalculator.js

Replace the current calculateDiscountedPrice which uses 250 with a helper and 500-based rounding.

Current (approximate) logic:

export const calculateDiscountedPrice = (price, percentage) => {
  if (!percentage || percentage <= 0) return price;
  const discounted = price * (1 - percentage / 100);
  return Math.round(discounted / 250) * 250;
};


Change it to:

export const arrondir500 = (val) => {
  return Math.round(val / 500) * 500;
};

export const calculateDiscountedPrice = (price, percentage) => {
  if (!percentage || percentage <= 0) return price;
  const discounted = price * (1 - percentage / 100);
  return arrondir500(discounted);
};
